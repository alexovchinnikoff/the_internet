# Установка и работа с проектом

## 📋 Что это за проект?

Это проект для автоматизированного тестирования, который использует:
- **Requests** - для тестирования API (бекенда)
- **Playwright** - для тестирования пользовательского интерфейса (UI)

---

## 🚀 Быстрый старт

### Шаг 1: Установка Python

**Что нужно знать:** Python - это язык программирования, на котором написан проект.

**Как проверить, установлен ли Python:**
```bash
python --version
# или
python3 --version
```
### Установка Python

Если Python не установлен:

1. Перейдите на официальный сайт: [python.org](https://www.python.org/)
2. Скачайте последнюю версию (**3.8 или выше**)
3. Запустите установщик и **ОБЯЗАТЕЛЬНО** отметьте галочку  
   `✅ Add Python to PATH`  
   — это позволит запускать Python из командной строки.
4. Нажмите **Install Now** и дождитесь завершения установки.

> 💡 **Проверка:** После установки откройте терминал (cmd) и выполните:
> ```bash
> python --version
> ```
> Если вы видите версию Python — всё готово.

### Шаг 2: Клонирование проекта
Что нужно знать: Клонирование - это скачивание проекта с GitHub на ваш компьютер.

### Шаг 3: Создание виртуального окружения

**Что это:** Виртуальное окружение — это изолированная папка, где будут установлены все библиотеки проекта. Это нужно, чтобы не засорять компьютер глобальными пакетами и избегать конфликтов версий.

---

### Создание виртуального окружения

Выполните команду в терминале (в папке проекта):

```bash
# Windows
python -m .venv .venv

# Mac / Linux
python3 -m .venv .venv
```

### Активация виртуального окружения

###  Windows (Command Prompt)
venv\Scripts\activate

### Mac / Linux
source venv/bin/activate

## Шаг 4: Установка зависимостей

**Что это:** Установка всех библиотек, которые нужны проекту. Все зависимости описаны в файле `requirements.txt`.

---

### Установка библиотек

```bash
# Установка всех библиотек из файла requirements.txt
pip install -r requirements.txt

# Установка браузеров для Playwright
playwright install

# Проверка установки
pip list  # покажет все установленные библиотеки# python_learning
